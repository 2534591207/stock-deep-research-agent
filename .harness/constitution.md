# Constitution — 项目根本大法

> SDD 第一阶段。**不可违背的规则**，约束所有开发与 AI 行为；任何 spec/plan/tasks/代码与本文冲突，以本文为准。
> 配套：产品原则见 `changes/*/PRD.md §2`；工程流程规则见 `.harness/rules/core/`。

## 1. 产品不可违背原则

1. **数字交给代码，模型只解释** —— LLM **绝不**计算行情指标；所有量化由确定性程序算。
2. **只摆证据与相关性，绝不断言因果** —— 事件只说"可能相关"，证据不足说"无法确认"，**绝不编造**涨跌原因或缺失数据。
3. **来源与时间永远透明** —— 每个数字/结论/事件带来源、数据时间、新鲜度。
4. **不构成投资建议** —— 不输出买卖指令、收益承诺、目标价、仓位；报告始终含免责声明。

## 2. 工程质量标准（不可违背）

- **TDD**：实现阶段先写失败测试 → 确认为正确原因失败 → 最小实现 → 重跑验证。
- **测试覆盖**：确定性计算模块（metrics / risk / market_view / 显著波动 / 事件分级）**≥ 90%**；整体有意义覆盖；**每个 AC 有对应测试**。
- **通过门槛（Definition of Done）**：lint / typecheck 0 error；相关测试全绿；`bash .harness/sensors/check-all.sh` 通过。
- **可复现**：金融数值内部用 decimal、带 `calculation_basis`、可用 PRD §10 自洽样例反推单测。
- **作者与评审分开**：评审由独立 agent 执行（`.harness/roles/reviewer.md`），不自审自批。

## 3. 技术约束

- 栈：**Python + FastAPI + 原生前端**；LLM = **OpenAI**。
- **provider / catalog 走接口 + 配置**，业务逻辑不写死厂商/固定股票/固定组合/固定句式。
- **失效与重跑判定永远在代码**；LLM 只产出意图候选（FollowupIntent），不做最终重跑决策。

## 4. 明确禁止（本期）

- LLM 计算行情指标；编造涨跌原因或缺失数据。
- 买卖建议 / 估值 / 目标价 / 仓位 / bull-bear 辩论。
- 账号系统、跨会话持久化、刷新后恢复。
- 向量库 / 全文 RAG / 扫描件 OCR。
- 多市场 provider（A 股等）本期**不实现**（但抽象不得阻挡未来接入）。

## 5. 范围护栏

- 覆盖**美国上市股票与 ADR**；单次 **≤ 3 只**、最长 **≤ 1 年**、每股深挖 **≤ 3 个异动**。
- 超出一律**明确告知、不静默截断**；非美国上市标的（港股/A股/OTC/加密）如实拒绝。
