## 1. 概述

为不懂股票代码、不会算指标、没空翻新闻的研究用户，提供一套后端 API：输入一句自然语言，自动识别美股公司、取行情、确定性计算市场风险、围绕异动找事件证据、横向比较，产出可下载英文研究报告。**研究辅助，不构成投资建议。**

范围：**后端（FastAPI）**。前端暂缓（API 即其契约）。

## 2. 用户故事

- **US-1** 作为研究用户，我想用一句话选 1–3 家美股公司并指定时间范围，**这样**我不必知道股票代码就能发起研究。
- **US-2** 我想拿到统一口径的走势与风险指标（收益、波动、回撤等），**这样**我能比较谁更强、谁更险。
- **US-3** 我想知道某段大涨大跌**可能**与什么事件相关（带时间和来源），**这样**我理解走势但不被编造的原因误导。
- **US-4** 我想得到一份**可下载的英文研究报告**，**这样**我能保存、分享。
- **US-5** 我想在**同一会话**里追问（重点看风险 / 为什么跌），**这样**不必从头再来。
- **US-6** 我想**上传财报**作补充证据，**这样**报告能结合我的材料（标文件名与页码）。
- **US-7** 当数据或证据不足时，我想被**如实告知**，**这样**我不会被假结论误导。

## 3. 功能需求（WHAT，承接 PRD）

1. 自然语言理解：识别 1–3 家公司（中/英/代码）+ 时间范围 + 关注点。
2. 公司识别：用支持名单 + 别名表裁决，覆盖美股与 ADR；不在范围如实说明、不编码。
3. 时间范围：自然语言→明确起止；硬上限 1 年；未来/无数据如实说明。
4. 市场指标（确定性）：区间收益、年化波动、负收益日波动、最大回撤、最大单日、显著波动、Data Coverage。
5. 规则化结论：Observed Market Risk（连续分数 + 绝对等级 + 组内排名）、Short-term Market View。
6. 事件研究：围绕最大单日异动检索事件，给 Event Attribution Confidence；事件方向仅展示、不进硬结论。
7. 经营风险（best-effort）：从 10-K Item 1A / 20-F Item 3.D 提取并归类。
8. 上传文件：PDF/TXT/MD 文本提取作补充证据，归属公司，标文件名+页码。
9. 横向比较：相同口径比较 + 相对风险排名（标"仅限本次所选股票与区间"）。
10. 报告：英文、每股 9 节、可下载 Markdown。
11. 会话与追问：单会话内记忆，三类追问（换角度复用 / 换公司时间重研究 / 问缺失补一步）。
12. 错误与降级：每条按 PRD §14；任何失败不编造数据。

> 量化全部由代码确定性计算，模型只理解/解释/提取（PRD §2 原则一/二）。

## 4. 验收标准（后端 / API 可测 · Given-When-Then）

**识别与理解**
- AC-1 _Given_ "比较英伟达、阿里巴巴和英特尔最近三个月" _When_ `POST /api/research` _Then_ 计划含 3 个锁定标的：NVDA/NASDAQ/common、BABA/NYSE/ADR、INTC/NASDAQ/common，时间解析为明确起止日。
- AC-2 _Given_ 含"小米"的多股请求 _Then_ 可识别的照常研究，小米标注"未找到美股标的"、不编码。
- AC-3 _Given_ 请求 5 只 _Then_ 默认取前 3、其余标注被推迟。

**确定性指标（单测 + 固定夹具）**
- AC-4 给定日线，区间收益/年化波动/负收益日波动/最大回撤/最大单日/Coverage 与手算一致。
- AC-5 `risk_score / absolute_level / Short-term Market View` 与 PRD §8 公式一致；用 PRD §10 样例反推自洽（risk_score≈50.4、medium、cautious）。
- AC-6 Coverage<0.8 或有效日线<10 → Undetermined / Insufficient，不参与相对排名。
- AC-7 最大单日 <2% → 标"无显著异动"，不强行找事件。

**事件与归因**
- AC-8 围绕最大单日异动检索，事件含 时间/来源/链接/direction；按来源分级+去重得 attribution_confidence。
- AC-9 无可靠事件 → 该异动 attribution=Low，但**整份研究仍出 Short-term Market View**（不变 Insufficient）。

**比较与报告**
- AC-10 完成后 `GET /api/research/{id}` 返回横向比较（收益/波动/回撤 + 相对风险排名 + caveat）。
- AC-11 `GET .../report?format=markdown` 返回英文报告，每股 9 节齐全，含来源、Observation period、英文免责声明、排名 caveat。

**会话与降级**
- AC-12 追问"重点比较风险" → 复用结果重组，不再调行情 provider。
- AC-13 行情 provider 失败 → 该股 failed 隔离，其它完成、报告标缺失。
- AC-14 未配 Key → 演示数据明确标注、不伪装实时。

**上传**
- AC-15 上传文本 PDF → 提取成功、归属某公司、报告标文件名+页码；与公开信息冲突时提示。

**多轮对话式 Agent（不是固定 Demo）**
- AC-16 _Given_ 用户输入支持名单中但非固定样本的股票（如 MSFT/AMZN/CRM/COST）_When_ 发起研究 _Then_ 通过 catalog/provider 识别并走完整流程，**不依赖固定代码或固定组合**。
- AC-17 _Given_ 用户用不同表达描述同一意图 _When_ 发起研究 _Then_ 正确识别公司/时间/关注点，而非只匹配固定句式。
- AC-18 _Given_ 已完成一次多股研究 _When_ 连续多轮追问（风险、事件、报告、上传、范围修改）_Then_ 始终正确引用当前股票、时间范围、已有结论和报告。
- AC-19 _Given_ 当前报告含多条事件和风险 _When_ 用户问"刚才阿里的第二条风险具体是什么" _Then_ 定位到 BABA 对应风险，不误用其它股票、不编造。
- AC-20 _Given_ 研究含 NVDA/BABA/INTC _When_ "把英特尔换成 AMD" _Then_ 只研究 AMD，复用 NVDA/BABA 仍有效结果，重新生成比较与报告。
- AC-21 _Given_ 当前为最近三个月 _When_ "改成最近一年" _Then_ 重新获取受影响股票的行情与事件，**旧指标不得用于新时间范围**。
- AC-22 _Given_ 已完成研究并生成报告 _When_ 上传属于某公司的 PDF/TXT/MD _Then_ 分析并归属、更新相关结论、生成新报告版本，不重复请求不必要的行情。
- AC-23 _Given_ 会话触发上下文压缩/摘要 _When_ 再问最初研究对象、时间范围、核心结论或当前报告 _Then_ 能从**结构化会话状态**恢复正确答案，不依赖完整聊天记录。
- AC-24 _Given_ 会话多次生成报告 _When_ "更新刚才的报告"或"上一版报告里那条风险" _Then_ 能区分当前版本与历史版本，引用正确内容。

> 注：不必真测"15 轮"，但**必须测"压缩/摘要触发后仍不丢关键状态"**（AC-23）。
