# 面试讲稿框架（骨架版 · 内容待填）

> 用途：现场向面试官讲这个项目。**这是框架，不是讲稿**——每节只给"这段要达成什么 + 待填要点"，具体话术后面再写。
> 总时长建议：**讲解 5–6 分钟 + Demo 3 分钟 + Q&A**。
> 一条主线贯穿全程：**从模糊业务 → 产品定义 → 关键取舍 → 可信交付**。技术名词（RAG / LangChain / FastAPI / 向量库…）全程不主动说。
> 北极星：让面试官看到"我是从业务和用户出发做产品决策的人"，而不是"拿到需求就写代码的工具人"。

---

## 0. 一句话定位（开场前自己心里默念）
- 🎯 这次我要证明的不是"我会做"，而是"我懂为什么这么做"。
- 🧩 待填：用一句话概括这个产品是什么、为谁、解决什么。

---

## 1. 我怎么理解这道题 ⏱~30s
- 🎯 目标：先点明"面试官只给了一个场景，把它变成一个有边界的产品，是我做的第一件事"。
- 🧩 待填：
  - [ ] 面试官给的原始场景（一句话复述）
  - [ ] 我把它定义成了什么产品（一句话）
  - [ ] 为什么"定义需求"本身才是这道题的重点

## 2. 用户与痛点 ⏱~40s
- 🎯 目标：锁定"为谁做、他真正卡在哪"。
- 🧩 待填：
  - [ ] 目标用户画像（非专业、不懂代码、不会算指标、没空翻新闻）
  - [ ] 他真正想要的一件事（job-to-be-done）
  - [ ] 现状下他要自己做哪些麻烦事

## 3. 我的产品定义与范围 ⏱~50s
- 🎯 目标：讲清"我决定做什么、不做什么"——展示取舍的勇气。
- 🧩 待填：
  - [ ] 核心 A：走势 + 风险 + 可下载报告
  - [ ] 加分 B：找异动 + 查证据 + 谨慎解释涨跌
  - [ ] 明确不做（及一句话理由）：账号系统 / 自动交易 / 复杂 RAG / OCR…（上传文件做轻量版：文本提取 + 补充证据）
  - [ ] 为什么 A 和 B 是一条链路的两个深度，不是两套功能

## 4. 需求拆解：从一句话到可执行步骤 ⏱~50s
- 🎯 目标：展示"把自然语言拆成机器能执行的研究流程"的能力。
- 🧩 待填：
  - [ ] 拆解链路：认公司 → 定时间 → 取行情 → 算指标 → 找异动 → 查证据 → 横向对比 → 出报告
  - [ ] 举一个槽位例子（中文名→证券身份、相对时间→明确日期）
  - [ ] 强调：哪些交给"业务规则"、哪些交给"模型理解"

## 5. 关键产品取舍（重头戏）⏱~90s
- 🎯 目标：这一节是和"工具人"拉开差距的地方——每条只讲"为什么"。
- 🧩 待填（每条一句"为什么"）：
  - [ ] 为什么数字交给代码、不交给 AI → 可信、可复现
  - [ ] 为什么"为什么涨跌"只摆证据、不下因果结论 → 诚实 > 炫技
  - [ ] 为什么只做当前会话、不做账号系统 → 三天只投核心价值
  - [ ] 为什么上传只做轻量版（文本提取、不做 OCR/向量库）→ 保留亮点又不拖垮主链路
  - [ ] 为什么做"看得见的并行编排" → 让"Agent 在调度工具"被看见
  - [ ] 为什么用免费、可复现的数据 → 研究原型阶段可信比实时更重要

## 6. 现场 Demo ⏱~3min
- 🎯 目标：让 Agent 的"理解 + 编排"被肉眼看见，而不是一次性吐答案。
- 🧩 待填（动作清单）：
  - [ ] 主流程输入语句（三股票 + 三个月 + 比风险）
  - [ ] 展示点：任务理解 / 研究计划 / 三股并行状态 / 找异动查证据 / 横向比较 / 报告下载
  - [ ] 连续追问一句（复用会话上下文）
  - [ ] 证据不足场景（展示"无法确认主要原因"，不编造）

## 7. 数据可信度与边界 ⏱~40s
- 🎯 目标：证明"我不会让产品骗用户"。
- 🧩 待填：
  - [ ] 伪实时参考价 vs 准确日线（部分市场的说明）
  - [ ] 来源 / 时间 / 新鲜度全程透明
  - [ ] 固定免责声明 + 不输出买卖指令

## 8. 失败处理与演示稳定性 ⏱~30s
- 🎯 目标：体现工程成熟度（知道真实世界会出错）。
- 🧩 待填：
  - [ ] 行情失败 / 新闻不足 / 单股超时 怎么降级
  - [ ] 带时间戳缓存快照（明确标注、不伪装实时）
  - [ ] 固定演示脚本，保证现场可控

## 9. 点题：取舍背后的我 ⏱~30s
- 🎯 目标：正面回应面试官对"工具人"的顾虑。
- 🧩 待填：
  - [ ] "AI coding 我当成已解决——Claude Code 几小时能写完"
  - [ ] "我三天主要的精力，花在理解业务、定义用户真正需要什么、做正确的减法上"

## 10. 未来扩展（可选，秀格局）⏱~20s
- 🧩 待填：更深的财报/估值分析 / 跨会话记忆 / 更严谨的事件归因 / 更多股票与市场

---

## 附：预判面试官会追问的问题（Q&A 准备清单 · 待填答案）
- [ ] 为什么不让模型直接算指标？万一算错怎么办？
- [ ] 你怎么保证"涨跌原因"不是 AI 瞎编的？
- [ ] 免费数据不准/限流，演示当场挂了怎么办？
- [ ] "部分市场实时价"会不会误导用户？你怎么处理？
- [ ] 为什么是"多个 Research Agent"，而不是一个 Agent 循环？这是真编排还是包装？
- [ ] 上传为什么只做轻量文本提取、不做 OCR/向量库？账号系统为什么不做？再给三天先做什么？
- [ ] 如果用户问"那我到底该不该买"，系统怎么回应？
- [ ] 这个产品和直接用 ChatGPT 搜一下有什么区别？（核心价值追问）
