# doc-only.md — placeholder for future DOC-* informational rules

This file is a placeholder. DOC-* rules are informational rules that describe
team conventions, onboarding notes, or documentation standards that do not
carry enforcement weight. They use `severity: INFO` and `mechanization: doc-only`.

Add DOC-* rules here as your harness matures. Example:

```markdown
# DOC-01 — ADR format

**ID:** DOC-01
**Severity:** INFO
**Mechanization:** doc-only
**Applies at:** design

## Statement
Architecture Decision Records (ADRs) use the Nygard format:
Title / Status / Context / Decision / Consequences.
```

No DOC-* rules are installed in the `custom` topology baseline.
